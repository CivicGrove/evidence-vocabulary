# Capacity Signal™ Evidence Vocabulary

An open specification for grading supplier claims on three independent axes —
provenance, event state, and review status. Eighteen values. Version 0.1.

The canonical, citable version of this specification is published at:

**https://capacitysignal.ca/spec/evidence-vocabulary/v0.1/**

That address is permanent and its content does not change once live. The
unversioned address `https://capacitysignal.ca/spec/evidence-vocabulary/` serves
the current version, which is today v0.1.

## What is in this repository

This repository holds the specification source only. It exists to give the text a
public commit history independent of the site that renders it.

- `evidence-vocabulary-v0.1.md` — the specification source.
- `LICENSE` — the Creative Commons Attribution 4.0 International licence.

The rendered page at the canonical address is the artifact of record. Where this
source and the rendered page differ in presentation, the rendered page governs.
